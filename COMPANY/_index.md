# COMPANY — Navigation Map

This folder is the business reference for Manhattanite. The files here define what Manhattanite is, how it talks, what it's building, and how it grows.

**Read this file first** to figure out which other file to open. Don't load everything every conversation.

---

## Read at the start of every Manhattanite conversation

1. `_index.md` (this file) — orientation
2. `memory.md` — quick state snapshot + pointers
3. The files relevant to the current task (see table below)

Open `memory/decisions.md` only if you need the full dated decision list. Open `memory/session-log.md` only when you need recent session context.

## When to read what

| Working on… | Files to open |
|---|---|
| Anything customer-facing (copy, listings, comms) | `product-vision.md` + `voice-and-copy.md` + `brand-guide.md` |
| Code, technical decisions, MVP scope | `mvp-spec.md` + `tech-architecture.md` |
| Growth, invites, founding members | `gtm-playbook.md` + `trust-and-moderation.md` |
| Community ops, moderation, listing curation | `trust-and-moderation.md` |
| Anything legal or policy-shaped | `legal-and-policy.md` |
| Daily PA work (email, calendar, ADHD) | `pa-rules.md` |
| Context on what we've decided before | `memory/decisions.md`, then `memory/session-log.md` if needed |

## File index

All built as of 2026-05-16:

- **pa-rules.md** — How Claude operates daily: Gmail, Outlook, Calendar, ADHD-aware defaults.
- **product-vision.md** — Why Manhattanite exists, two-tier model, named personas, positioning.

- **memory/decisions.md** — Distilled list of strategic decisions, dated.
- **memory/session-log.md** — Chronological session log.

## Memory protocol

At the start of every Manhattanite conversation:

1. Read `_index.md` (this file) to orient
2. Read `memory.md` for the quick state snapshot
3. Drop into `memory/decisions.md` or `memory/session-log.md` only if a specific decision's full text or recent session context matters

At the end of every meaningful session:

- Append a dated entry to `memory/session-log.md` (newest at top)
- Update `memory/decisions.md` if a strategic decision was made or revised
- Update the "Quick state" section of `memory.md` if anything material changed
