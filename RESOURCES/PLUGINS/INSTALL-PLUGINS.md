# Installing Your CoWork OS Plugins

CoWork OS plugins install from the Better Creating marketplace. The marketplace always has the latest plugins available for your system.

There are two ways to install them.

---

## Option 1: Install from the Better Creating Marketplace

This is the recommended method.

1. Open a CoWork session in the Claude desktop app
2. Click **Customise** (the sliders icon in the bottom-left of the sidebar)
3. Go to **Plugins**
4. Click the **+** button next to "Personal plugins"
5. Select **Add marketplace**
6. Enter: `bettercreating/cowork-os-plugins`
7. Click **Sync**
8. You'll see a safety notice — this is normal (see below). Click **Sync** to confirm
9. Now click **Browse plugins** and go to the **Personal** tab
10. You'll see both plugins listed under Better Creating — click the **+** on each one to install

That's it — your plugins are now ready to use. Check back any time for new plugins and updates.

---

## Option 2: Using Claude Code?

If you're using CoWork OS in the Claude Code tab instead of CoWork, the process is the same — open **Customise > Plugins**, add the Better Creating marketplace, and install your plugins from there.

---

## About the Safety Warning

When you add the marketplace or install a plugin, you'll see a warning from Anthropic saying they can't guarantee the safety of third-party plugins. This appears for every plugin that isn't in Anthropic's official marketplace — it's not specific to CoWork OS. The plugins included here were built by Simon at Better Creating and only contain text-based instructions and connections to your own tools. Nothing risky. Just click confirm and you're good to go.

---

## Troubleshooting

**Plugins don't appear after adding the marketplace**
Make sure you typed the marketplace address exactly: `bettercreating/cowork-os-plugins`. Check for typos.

**Plugin installs but skills don't appear**
Close and reopen the Claude desktop app. The skills should appear after a restart.

**Still stuck?**
Email Simon at notion@bettercreating.com — include what you tried and any error message you saw.
