Six decisions baked into this

  1. It sits above the grid, not in it. A welcome tile shaped like a listing reads as a placeholder or a bug before it reads as a welcome. This is unmistakably page furniture.
  2. The empty state stays underneath it. That panel already exists in the code and already says the right thing. The welcome explains the network; the empty state explains the grid. Two different jobs, so two elements.
  3. It admits the board is empty. "Nobody has listed anything yet" is the line. A private network that pretends to be busy on day one loses the only thing it's selling.
  4. Three columns, not a wall. How it works, who's here, house rules — one short paragraph each. The full rules live on their own page and this links twice to them.
  5. It collapses rather than disappears. Artboard B: once listings exist it becomes one line that a member can hide for good. New members joining in October still meet the full version, because the trigger is "you haven't posted yet", not "the site is new".
  6. One primary action. "Post the first listing." A welcome that doesn't ask for anything is a poster.
One line is deliberately missing. The pitch says "if you break the rules, they go too" — and the product still has no rule for what happens to people a removed member vouched for. So the "Who's here" column says their name stays beside yours, which is true today, and stops there. Write the shared-liability rule and that column gets its strongest sentence back.
